# Expedientes CEMEPI

Aplicación web de expedientes psicológicos del Centro Mexicano de Plenitud Humana, S.C. (CEMEPI).

- Acceso solo con cuenta autorizada por la Dirección.
- Los datos **no** están en este repositorio: se guardan en una base de datos protegida (Supabase) con inicio de sesión y reglas de seguridad por usuario.
- `config.js` contiene únicamente la dirección del proyecto y su clave **pública** (publishable), diseñada para usarse en el navegador.
